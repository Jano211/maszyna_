# Źródła ortofoto, terenu i map dla edytora MaSzyny poza geoportal.gov.pl.
# Plik kładzie się w folderze symulatora jako editor/foreign_sources.txt. Bez niego edytor korzysta wyłącznie z geoportal.gov.pl.
# Edytor czyta go przy starcie i po kliknięciu „Wczytaj ponownie inne źródła” w oknie ortofoto.
#
# Każde źródło zajmuje jedną linijkę: <ortho|terrain|map> <nazwa> <wms|wcs|xyz> klucz=wartość ...
# W wartościach nie może być spacji; w credit= i title= podkreślnik oznacza spację.
#   ortho / terrain  uzupełniają ortofoto / teren tam, gdzie geoportal.gov.pl nie ma danych (za granicą)
#   map              warstwa do wyboru zamiast ortofoto (lista „Warstwa” w oknie ortofoto); title= to nazwa na liście
#   url=        adres zapytania: dla wms/wcs {bbox} (minx,miny,maxx,maxy w układzie crs=, x na wschód), {width}, {height},
#               osobno {minx} {miny} {maxx} {maxy} (dla WCS 2.0: SUBSET=E({minx},{maxx})&SUBSET=N({miny},{maxy}));
#               dla xyz {z} {x} {y} (kafle Web Mercator jak w OpenStreetMap)
#   crs=        kod EPSG układu wms/wcs: 2180, 2176-2179, 3040-3051, 25828-25838, 32628-32638, 3067, 3346, 4026, 3857, 4326, 4258
#   area=       zachód,południe,wschód,północ w stopniach; poza tym obszarem źródło nie jest odpytywane (bez area: cały świat)
#   priority=   mniejsza liczba = źródło brane wcześniej; geoportal.gov.pl zawsze ma pierwszeństwo
#   resolution= najmniejszy piksel, o jaki warto pytać, w jednostkach crs= (wms/wcs); max= największa szerokość/wysokość zapytania
#   zoom=       xyz: najgłębszy poziom zdjęć albo poziom kafli terenu
#   encoding=terrarium  xyz teren: wysokości zakodowane w kolorach jak w kaflach Mapzen/AWS
#   offset=     teren: metry dodawane do wysokości albo auto (wyliczane tam, gdzie dane stykają się z polskimi)
#   blend=      teren: na ilu metrach przy krawędzi wysokości są dociągane do polskich
#   nodata=     teren: wartość oznaczająca brak danych (oprócz tej zapisanej w GeoTIFF-ie), np. 0 poza granicą kraju
#   feather=    ortho: na ilu metrach polskie zdjęcie przenika w zdjęcie tego źródła
#   credit=     autor danych, wyświetlany pod oknami
#   tile=       map: kafle edytora tyle razy większe (np. 4 = 1024 m zamiast 256 m): mapa sięga tyle razy dalej przy tej samej liczbie kafli
#   magnify=    mapa pobierana z pikselem tyle razy większym (1, 2, 4, 8): napisy i znaki tyle razy większe na ziemi, mniej szczegółów
#
