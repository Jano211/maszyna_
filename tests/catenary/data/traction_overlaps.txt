// Edytor stawia z nich całe przęsło jednym kliknięciem: słupy w odległościach z karty, wysięgniki obu sieci, poderwanie przewodu
// schodzącego do kotwienia, kotwienia na obu końcach i dwa łańcuchy. Sieć A dochodzi do przęsła (łańcuch, który się ciągnęło),
// sieć B z niego wychodzi (nowy łańcuch, ciągnie się go dalej).
//
// overlap <karta> networks <kody typów sieci> [curve] : <opis>
//   z <m>            odsuw każdej sieci od osi toru na słupach krzyżowych (przewody 2z od siebie); na łuku z tablic 0027 - tu na oko
//   lift <m>         poderwanie przewodu schodzącego do kotwienia na słupie krzyżowym
//   common <m>       wspólna bieżnia (c z karty) - tylko do opisu
//   hk <m>           wysokość konstrukcyjna sieci pracującej (lina nad przewodem)
//   anchor <lina> <przewody>   wysokość kotwienia liny i przewodów nad główką szyny (rozdzielone: 7,00 / 6,30)
//   pole <nazwa> <od poprzedniego, m> <sieć A> <sieć B> [same]
//                    rola sieci na słupie: anchor - kotwienie, work - przewód roboczy, lift - poderwany, - - nie ma jej tu;
//                    "same" - na tej samej konstrukcji co poprzedni wpis (wysięgniki rozstawione na konsoli 4890).
//                    Słup krzyżowy z dwiema sieciami: jeden wysięgnik „z” (120x) sieci pracującej, poderwana przechodzi obok swobodnie
//                    (Jan 2026-10-31); obie pracujące (13-0062-35, słup środkowy): dwa 120x, lina drugiego nad pierwszym. Sam „lift”
//                    na słupie (słupy K kart K+P): zwykły wysięgnik podniesiony o lift. Kotwowy - sam słup (albo istniejący do 6 m)
// endoverlap
