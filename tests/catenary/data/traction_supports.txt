//   nazwa       - tak jak w scenerii we wpisie suspension: "pole <nazwa> x y z"

// ---- mocowanie do slupa ----------------------------------------------------------------------------------------
// mount <nazwa> axis|eye <Y> <Z> [hinge <czesc> <Y> <Z>] [rod <czesc>] [back <czesc>] [twin <czesc>] endmount
